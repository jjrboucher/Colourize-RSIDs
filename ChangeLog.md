# v1.4 Change Log



* Corrected colour application so that runs inheriting rsidR from their parent paragraph are colourized when the document is saved.
* Replaced regex-based XML modification with structured XML processing for more reliable handling of WordprocessingML.
* Preserved existing run formatting while adding or updating the w:color property.
* Added a persistent vertical scrollbar to the rsidR Values pane.
* Improved mouse-wheel scrolling when the pointer is positioned over an rsidR row or one of its controls.
* Updated the application title, logs, and documentation to version 1.4.
* Updated the user guide and README.md to describe inherited paragraph-level rsidR values, scrolling, and output-validation procedures.
